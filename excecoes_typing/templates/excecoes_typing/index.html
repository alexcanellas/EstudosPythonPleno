⚠️ Exceções e Type Hints

Hierarquia de exceções, exceções customizadas, try/except/else/finally completo, encadeamento com raise...from, e os tipos mais usados do módulo typing. O código de verdade está em:

excecoes_typing/exemplos.py

Roda as funções demo_* no shell do Django:

python manage.py shell
>>> from excecoes_typing.exemplos import *
>>> demo_hierarquia_excecoes()

1. Hierarquia de exceções

Toda exceção do Python herda de BaseException, mas na prática você lida com a árvore abaixo de Exception. KeyError e IndexError, por exemplo, são ambas LookupError — dá pra capturar as duas com um except LookupError. A ordem dos blocos except importa: do mais específico pro mais genérico.

Ver: demo_hierarquia_excecoes()

2. Exceções customizadas

Criar suas próprias exceções, herdando de Exception, deixa o código mais expressivo e permite carregar dados extras junto com o erro — muito usado em APIs pra mapear erros pra respostas estruturadas (é assim que o DRF mapeia exceções pra status HTTP).

Ver: SaldoInsuficienteError, demo_excecao_customizada()

3. try / except / else / finally

else roda só quando não houve exceção (separa "o que pode falhar" de "o que fazer quando deu certo"); finally roda sempre, com ou sem erro — ideal pra limpeza de recursos.

Ver: dividir(), demo_try_except_else_finally()

4. raise ... from ... — encadeamento

Quando você captura uma exceção e levanta outra no lugar dela, from preserva a exceção original como causa (acessível via __cause__), em vez de esconder o contexto real do erro. Isso é essencial pra debugar em produção.

Ver: buscar_usuario(), demo_raise_from()

5. Type hints: Optional, Union, List, Dict, Generic

Type hints não mudam o comportamento em tempo de execução, mas ajudam ferramentas (mypy, IDEs, DRF, FastAPI) a pegar erros antes de rodar. Optional[str] = pode ser str ou None; Union[int, str] = aceita os dois tipos; Generic[T] permite criar classes que mantêm a informação de tipo (ex: uma Caixa[int] sabe que devolve int).

Ver: buscar_nome(), processar_id(), Caixa, demo_type_hints_basicos()
